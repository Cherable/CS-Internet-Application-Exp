# orangible · 热带水果购物网站

Internet Application 课程实验，采用 Django、MySQL 和服务端模板。界面为雨林纪录片主题，包含全屏序章、虚化雨林背景、紧凑水果卡片和商品故事。

## 功能

- 注册、登录、注销，水果检索与商品详情。
- 应季精选、即食/临期优惠、全部水果；默认按近30日销量排序。
- 购物车、事务下单、库存预留、取消、演示付款和订单历史。
- 后台商品、发货邮件任务及销售统计管理。
- 持久化每日供需模拟、人工补录与订单销量合并，页面同步排名；折扣每日更新，成交价格保存快照。

## 技术组成

config/ 为应用配置，shop/ 为业务、模型和迁移，templates/ 与 static/ 为界面。生产编排使用 compose.production.yaml，配合 Dockerfile、deploy/ 与 GitHub Actions。

水果示例目录由 seed_fruits 管理，每日行情由 fruit-clock 服务维护。历史数据库迁移属于当前应用的必要组成。

## 实现范围

支付为演示，未真实扣款；邮件默认预览。销量、季节与供需含模拟设定，产区故事不构成实际供货证明。云服务器、容器运行和真实邮件收件尚待验收。

原创代码采用 MIT 许可证。


热带果实目录现包含14种水果、20个商品批次（示例数据）。过季或缺货商品默认收录于底部折叠区，点击“加载更多”展开，整张卡片灰化，缺货商品不能加入购物车。正常在售商品保持彩色，库存或季节状态改变时重新归类。图片来源与当前验证记录分别见 docs/IMAGE_CREDITS.md 和 docs/validation/（报告所在目录中的对应文件）。


新季预约与海外热带栏目支持指数预约折扣（最低八折）、预约锁价与结算兑现。所有商品具有预计发货/运输/送达时长及赏味期；海外商品展示带公布日期的ECB官方参考汇率和有条件的税费情景。规则及验证范围见[预约与履约设计](docs/COMMERCE.md)。示例初始化包含 seed_fruits 与 seed_commerce，后者新增3个持久预约批次及海外香蕉批次，不滚动延期或自动补充库存。


合并窗口宽度701–1000px时，商品卡片为单列通栏，宽屏保留双列。各水果详情增加培育与采摘的果园手记场景；番石榴、芒果和香蕉配有生长或采摘摄影，标注摄影来源与示例场景性质。当前20个商品故事页以及887、1440、390px布局已通过浏览器检查。
