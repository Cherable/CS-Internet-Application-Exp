# orangible 在线购物网站

Internet Application 课程实验，采用 Django、MySQL 与服务端模板实现热带水果购物系统。界面采用雨林纪录片风格，以深林绿、米白和水果摄影呈现。

## 系统功能

- 顾客注册、登录、注销，商品浏览、关键词查询与分类筛选。
- 购物车、事务化下单、库存预留、订单取消与订单历史。
- 明确标注的演示付款、发货通知任务及失败重试。
- 后台商品管理、订单发货、销售数量与金额统计。

## 技术实现

Python 3.12、Django 5.2、MySQL，Django ORM 管理数据访问与迁移。订单采用价格快照、数据库事务、行锁、条件库存更新和唯一结算令牌。权限控制限定顾客访问自己的订单，销售管理采用 staff 与模型权限。

生产部署结构由 Gunicorn、Nginx 和 MySQL 组成，配置见 Dockerfile、compose.production.yaml 与 deploy/。GitHub Actions 包含 SQLite/MySQL 测试及容器构建检查。

## 热带水果目录

首页包含雨林风土叙事、应季精选、即食/临期优惠和全部水果。默认按近30日销量排序；销量合并模拟、人工补录与本站付款订单，模拟数据持久化按日延续。优惠由示例季节供给与需求关系按日计算，订单保存价格快照。销售数据含模拟值，非实时市场行情。产地文案及摄影素材不构成实际供货证明。

水果示例数据由 seed_fruits 命令建立，新增迁移 0003；fruit-clock 服务负责每日更新。原数据库、历史订单与旧商品记录保留。MySQL 8.0.45 的 46 项测试通过，浏览器验证记录见 docs/fruit-redesign/。
