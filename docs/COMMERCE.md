# 预约、跨境参考信息与履约模型

系统新增「新季预约」和「海外热带」入口。示例目录共14种水果、20个商品批次：17个常规/熟度批次、3个预约批次；菲律宾香蕉与其他香蕉共用水果品种分类。榴莲、山竹、红毛丹、牛油果及菲律宾香蕉被标记为海外示例。原有摄影复用于相同水果，不作为真实供应链证明。

## 预约价格

设距离预计上架日期的整天数为 d，基准价格为 P。预约减价比例为：

`r(d) = 0.20 × (exp(min(max(d,0),30)/14) − 1) / (exp(30/14) − 1)`

预约价为 `P × (1 − r(d))`，最终金额四舍五入到分。30天及更早预约为八折；临近上架时，减价比例按指数关系递减，上架当天归零。预约优惠与当日供需折扣不叠加。

预约需登录，保存价格、数量和预计上架日期快照；重复提交返回原预约，不扣定金，不虚构库存预留。上架前不能加入购物车或结算。上架后实际有货时，结算取锁定价与当日价中较低者，使用数量不超过预约数量。一条预约仅用于一笔订单；取消待付款订单恢复预约使用资格。少量下单也会消耗整条预约，未用数量不拆分；该规则与数量上限由事务层执行。上架日期以后台实际商品日期为准，预约记录保留创建时的日期。

示例预计日期以首次初始化当天起算，分别为7、21、35天后；再次初始化不滚动改期，不补造库存。预约是需求登记，不保证供货，上架后的实际批次与库存由后台维护。

## 汇率与税费

汇率来源为[欧洲中央银行官方参考汇率](https://www.ecb.europa.eu/stats/policy_and_exchange_rates/euro_reference_exchange_rates/html/index.en.html)，通常按工作日公布，适用于参考展示，不能称为实时成交价。程序使用校验证书的HTTPS读取官方XML，以 EUR 为中间币计算 CNY 交叉汇率。保留公布日期、抓取时间和失败状态；服务端一小时内不重复抓取，浏览器每分钟读取缓存。没有可用数据时显示不可用；抓取失败时保留上次数据并标记缓存。人民币价格是演示结算基准，换算不改变支付金额。

税费展示采用条件情景：商品若在准入清单中，满足跨境零售、身份、三单及额度条件，并适用增值税9%、消费税0%，则关税暂按0%、增值税法定应纳税额按70%征收，情景综合比例为6.3%。2018年政策将单次与年度限额调整为5000元、26000元。页面中的金额示例仅用展示货值乘比例，未包括运费与保险费，不计入演示结算，不代表实际完税价格或海关核定金额。全部商品尚未核定HS编码、准入及实际进口渠道，不能推定所有鲜果符合上述条件。

## 履约与赏味期

每个商品保存平均备货小时、运输配送小时和签收后最佳赏味天数。总送达时长为两段小时之和除以24。国内默认24小时备货、48小时配送；海外示例采用96至120小时运输，可能含海外段与清关等待。预约商品从上架后开始计算。

这些是模拟配送至中国大陆的计划平均值，未连接承运商运单，非真实统计或时效承诺。赏味建议受成熟度、温度和状态影响，以实际标签为准；临期批次不得超过所标截止日期。后台可按实际批次调整全部字段。
