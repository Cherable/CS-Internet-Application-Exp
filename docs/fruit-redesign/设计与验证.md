# orangible 热带水果主题

视觉：深林绿、米白、果实金色。雨林摄影开场、风土叙事、应季/即食优惠/全部水果导航、关键词搜索、销量/价格/新上架排序，简约水果详情页。6 种水果、8 个商品批次；旧商品下架，历史订单保留。图片素材与署名见 ../IMAGE_CREDITS.md。

## 数据规则

销量口径为近30个北京时间自然日的模拟销量 + 人工补录 + 本站已付款/已发货订单数量。三种来源独立计数；重复付款不会重复计入。补录字段位于后台“水果每日数据”，仅有权限的管理人员可改，不包含本站已统计订单。前台页面每5秒同步销量与排序，刷新页面则立即读取最新值。

模拟初始回填30天，然后按日增量写入 FruitDay，产品/日期唯一，刷新不会重新随机。遗漏日期逐天补齐，旧数据不覆盖。后续需求按前日模拟需求的80%、当季目标的20%与日期确定性扰动组合；前日人工补录和实际订单以有限权重影响次日趋势。销量滚动窗口每天淘汰最旧一天。

供给 S 根据月份旺季系数和确定性日扰动生成，需求 D 为当日模拟销量。常规优惠百分比为 clamp(round(25×(S/D−1)),0,25)；即食至少20%，临期至少35%。折扣每天固定，人工补录不重写当日折扣。季节日历、供需与销量均为演示设定，不是实时市场数据或官方预测。实际价格为原价×(1−优惠率)，Decimal 四舍五入到分；订单保存同一报价快照，已下单价格不随次日变化。

临期批次明确显示食用截止日，过期隐藏并阻止下单；演示日期不自动延长，需要管理人员更新真实批次。示例产区与种植故事不表示已获得供应链认证。

每日进程 run_fruit_clock 根据北京时间换日更新，Compose 增加 fruit-clock 服务。进程未运行或电脑关闭期间，下一次访问可幂等补齐每日数据；本地进程不能在关机时执行。

## 验证

SQLite 回归及 MySQL 8.0.45 独立实例测试结果分别见 test-results.txt 和 mysql-test-results.txt。新增测试覆盖日数据幂等、滚动窗口、即时补录/付款、优惠价格快照、过期批次、筛选排序和权限。浏览器验收及截图独立保存；原阶段证据保留。Docker/Compose 云上运行仍待实际 ECS 验证。
